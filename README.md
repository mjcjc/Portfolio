# AI Game Maker 포트폴리오

멀티플레이 게임 서버를 개발해 왔습니다. 이번 프로젝트에서는 AI에 Unity 프로토타입 구현을 맡기고, 직접 플레이하고 시연하면서 뽑기 조작과 배치 규칙을 다듬었습니다.

## 대표 프로젝트 · 랜덤 타워 디펜스

게임 내 재화인 크레딧으로 포탑을 뽑고, 적이 몰려오는 두 길에 배치해 기지를 지키는 Unity 게임입니다. 전투 전에 어느 길로 적이 더 많이 올지 예고되며, 플레이어는 그에 맞춰 포탑을 옮기거나 합성해 30차례의 공격을 막습니다. [게임 저장소](https://github.com/mjcjc/TowerDefense)

### 포탑을 연속으로 뽑을 때 반복 조작 줄이기

초기 버전에서는 포탑을 한 번 뽑을 때마다 놓을 빈칸부터 골라야 했습니다. 시연에서 여러 번 뽑을 때 같은 조작이 반복된다는 피드백을 받았습니다. 저는 뽑기 버튼을 누른 뒤 포탑이 놓이는 과정부터 살펴보고, 버튼을 한 번 누르면 무작위 빈칸에 바로 놓이도록 바꿨습니다. 전투 전에는 포탑을 자유롭게 옮길 수 있어, 플레이어가 공격 예고를 보고 어느 길을 막을지 정할 수 있습니다.

### 냉각포의 효과를 전투 화면에 보여주기

냉각포는 주변 적의 이동을 늦추고 한 발로 여러 적을 공격하는 합성 포탑입니다. 초기 화면에서는 어떤 적이 느려졌고 한 발로 몇 마리를 잡았는지 파악하기 어려웠습니다. 저는 두 정보를 전투 중에 보여주기로 정하고, AI에 감속된 적의 표시와 한 발로 잡은 적의 수를 띄우는 기능을 맡겼습니다.

전투 규칙은 Unity 화면을 띄우지 않고 자동 테스트로 확인했습니다. 테스트는 냉각포를 배치한 뒤 전투를 진행해 적이 실제로 느려지는지, 한 발로 여러 적을 처치하는지 검사합니다.

### 공격 예고가 배치 판단으로 이어지게 하기

게임 속 적 지휘관은 어느 길에 어떤 적을 보낼지 여러 후보를 시험해 기지에 줄 예상 피해를 비교합니다. 예측과 실제 전투에 같은 전투 규칙을 적용하며, 예고된 편성은 전투가 시작될 때까지 유지됩니다. 플레이어는 예고를 보고 포탑을 옮길 수 있고, AI 판단 화면에서 후보별 예상 피해와 선택 기준을 확인할 수 있습니다.
