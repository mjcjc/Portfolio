# 민준기 | 게임 개발 포트폴리오

## PROFILE

음에는 TCP로 두 플레이어의 화면을 맞추는 것부터 배웠습니다. 블록 게임에서 같은 경기의 승자가 화면마다 다르게 보였을 때, 패킷이 도착하는지만 확인해서는 문제를 풀 수 없었습니다. 서버가 부여한 플레이어 번호가 화면에 표시되기까지 추적하면서, 연결된 기능 사이에서 어떤 값을 기준으로 삼아야 하는지 배웠습니다. 이후에는 IOCP 서버의 송수신 구조를 다루고, 농장 게임에서는 플레이어 이동과 작물·월드 상태를 처리하며 서버가 책임지는 범위를 넓혔습니다. 앞으로는 여러 플레이어가 동시에 행동하거나 연결이 끊겼을 때도 게임 상태가 일관되게 유지되는지 재현하고, 그 결과를 바탕으로 서버 구조를 개선하는 개발자로 성장하고 싶습니다.
