# 민준기 | 게임 개발 포트폴리오

## PROFILE

처음에는 TCP로 두 플레이어의 화면을 맞추는 것부터 배웠습니다. 블록 게임에서 같은 경기의 승자가 화면마다 다르게 보였을 때, 패킷이 도착하는지만 확인해서는 문제를 풀 수 없었습니다. 서버가 부여한 플레이어 번호가 화면에 표시되기까지 추적하면서, 연결된 기능 사이에서 어떤 값을 기준으로 삼아야 하는지 배웠습니다. 이후에는 IOCP 서버의 송수신 구조를 다루고, 농장 게임에서는 플레이어 이동과 작물·월드 상태를 처리하며 서버가 책임지는 범위를 넓혔습니다. 앞으로는 여러 플레이어가 동시에 행동하거나 연결이 끊겼을 때도 게임 상태가 일관되게 유지되는지 재현하고, 그 결과를 바탕으로 서버 구조를 개선하는 개발자로 성장하고 싶습니다.

### 1. 랜덤 타워디펜스

| 구분 | 내용 |
| --- | --- |
| 장르·플랫폼 | 싱글플레이 타워디펜스 · Windows PC · Unity/C# |
| 일정 | 2026.11 · Unity 프로토타입 공개 |
| 담당 | 플레이 개선 방향 결정, AI에 구현 조건 전달, 시연과 테스트 |

30웨이브 동안 북쪽과 남쪽에서 몰려오는 적을 막는 게임입니다. 시연에서 포탑을 뽑을 때마다 빈칸을 골라야 하는 불편을 확인했습니다. 버튼 한 번으로 무작위 빈 슬롯에 배치하되, 공격 예고를 본 뒤 포탑을 옮기는 선택은 유지했습니다. 냉각포의 효과는 감속된 적 발밑의 원과 한 발 처치 수로 표시했습니다.

[상세 소개](tower-defense.md) · [전투·합성·AI 예측 설계와 코드](https://github.com/mjcjc/TowerDefense#readme)
