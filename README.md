# AI Game Maker 포트폴리오

멀티플레이 게임 서버를 개발해 왔습니다. 이번 프로젝트에서는 AI에 Unity 프로토타입 구현을 맡기고, 직접 플레이하고 시연하면서 뽑기 조작과 배치 규칙을 다듬었습니다.

## 대표 프로젝트 · 랜덤 타워 디펜스

크레딧으로 뽑은 포탑을 합성하거나 옮겨 30웨이브 동안 코어를 지키는 Unity 게임입니다. 다음 공격의 주력 경로를 보고 포탑을 한쪽에 모을지, 두 길에 나눠 둘지 결정합니다.

### 연속 뽑기의 반복 조작 줄이기

초기 시연에서는 포탑을 뽑을 때마다 빈 슬롯을 먼저 골라야 했습니다. 연속 뽑기에서 같은 조작이 반복된다는 피드백을 받아, 뽑기와 전술적인 배치를 두 단계로 나눴습니다. 현재 버전에서는 버튼을 한 번 누르면 포탑이 무작위 빈 슬롯에 배치됩니다. 플레이어는 준비 중에 포탑을 옮겨 공격 예고에 대응할 수 있습니다.

### AI와 작업을 나눈 방식

AI에 전투 로직과 Unity 화면을 포함한 초기 프로토타입 구현을 맡겼습니다. 저는 실행 화면을 시연하고 조작과 전투에서 보완할 부분을 피드백받아 다음 수정 범위를 정했습니다. 뽑기에서는 연속 입력을 줄이면서 배치 선택을 유지하는 데 집중했습니다. 전투에서는 조합의 효과를 알아보기 쉽도록 냉각포의 감속 표시와 다중 처치 연출, 경로별 돌파 결과를 추가하는 방향으로 AI에 수정을 요청했습니다.

전투 모델 검사에서는 냉각포가 적을 감속시키고 한 발로 여러 적을 처치하는 상황과, 서로 다른 세 가지 시드로 30웨이브를 클리어하는 경로를 확인했습니다.

### 공격 예고가 배치 판단으로 이어지게 하기

게임 속 적 지휘관은 여러 웨이브 편성을 시험해 코어에 줄 예상 피해를 비교합니다. 예측과 실전에 같은 전투 모델을 쓰고, 한번 공개한 편성은 전투 시작까지 유지합니다. 플레이어는 예고를 바탕으로 포탑을 옮길 수 있으며, 판단 화면에서 후보별 예상 피해와 선택 기준을 볼 수 있습니다.
